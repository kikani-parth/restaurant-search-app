# Foodemy

Foodemy is a restaurant search app built with React Native that allows users to easily search for restaurants. Whether you're looking for a specific cuisine, a local favorite, or exploring new dining options, this app offers a streamlined and responsive user experience.


## Features

- Search Functionality: Quickly find restaurants by name, cuisine, or location.

- Restaurant Listings: Browse through a list of restaurants with key details such as ratings, location, and brief descriptions.

- Intuitive UI: Built with React Native and Expo to deliver a smooth and responsive experience across multiple devices.

- Easy Navigation: Seamlessly navigate between search results and detailed restaurant views.


## Installation

1. Clone the repository:

```bash
git clone https://github.com/kikani-parth/restaurant-search-app.git
cd restaurant-search-app
```

2. Install dependencies:

```bash
npm install
```

3. Run the app:

```bash
npx expo start
```
    
## Usage

- Search: Use the search bar on the home screen to enter a restaurant name, cuisine, or location.

- View Details: Tap on a restaurant listing to view additional details and reviews.

- Navigation: Easily switch between the search results and detailed views for an optimal browsing experience.
